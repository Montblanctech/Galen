# Packaged data: LSJ-Gold 0.1

`lsj_gold.csv` is LSJ-Gold 0.1 (57,278 rows), copied unchanged from `release/lsj-gold-0.1/lsj_gold.csv` of the
Galen repository. Licence: CC BY 4.0 (see `LICENSE`). Underlying texts: First1KGreek (CC BY-SA 4.0), Perseus LSJ
XML (CC BY-SA 3.0).

Columns: headword, headword_key, author, work, cited_edition, locator, unit, token_index, surface, validation,
quoted_form, lsj_part, entry_key, status. Used by `greek-lemma-audit lsjgold`.
