# Packaged data: LSJ-Gold 0.1.2

`lsj_gold.csv` is LSJ-Gold 0.1.2 (70,198 rows, 54 authors, 2026-11-11), copied unchanged from `release/lsj-gold-0.1.2/lsj_gold.csv` of the
Galen repository (concept doi:10.5281/zenodo.21561962). It is LSJ-Gold 0.1.1 with its 652 weakest loci read blind (313 dropped), a
repeated locus counted once, and 49 tokens gold under two headwords set aside; see `release/lsj-gold-0.1.2/README.md`. Licence: CC BY 4.0 (see `LICENSE`). Underlying
texts: First1KGreek (CC BY-SA 4.0), Perseus LSJ XML (CC BY-SA 3.0).

Columns: headword, headword_key, author, work, cited_edition, locator, unit, token_index, surface, validation,
quoted_form, lsj_part, entry_key, status. Used by `greek-lemma-audit lsjgold`.
