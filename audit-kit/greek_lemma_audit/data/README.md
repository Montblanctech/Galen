# Packaged data: LSJ-Gold 1.0

`lsj_gold.csv` is LSJ-Gold 1.0, the stable release (70,033 rows, 54 authors, 2026-11-11), copied unchanged from
`release/lsj-gold-1.0/lsj_gold.csv` of the Galen repository (concept doi:10.5281/zenodo.21561962): every locus with a reason for
doubt read blind and decided, the rest sampled, residual error stated; see `release/lsj-gold-1.0/README.md`. Licence: CC BY 4.0 (see `LICENSE`). Underlying
texts: First1KGreek (CC BY-SA 4.0), Perseus LSJ XML (CC BY-SA 3.0).

Columns: headword, headword_key, author, work, cited_edition, locator, unit, token_index, surface, validation,
quoted_form, lsj_part, entry_key, status. Used by `greek-lemma-audit lsjgold`.
