Galen Density Project

The method on other texts

The pipeline that made Galen First Drafts runs on any Greek or Latin text that has a digital edition and a dictionary. These pages test it on texts that already have a complete human English translation, so the machine drafts can be scored against a person's. They are not new translations.

  • Vitruvius, On Architecture, Book 3 · De architectura, liber III · 29 passages, 4,059 Latin words, 6 failing two or more checks · agreement with M. H. Morgan's 1914 translation on the key terms: 64.0% and 66.0%

For comparison, the Galen drafts of Composition of Drugs by Kind agree with their human reference on 63.5% and 66.4% of the key terms. The same two models, the same prompt wording, and the same checks and thresholds are used throughout. How it works, and how to run it on another text: RECIPE.md. Report a correction.
