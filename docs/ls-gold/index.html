How the loci were made

window = cited unit ±1 sibling (editions of a work tried in file order; chapter aliases; pr/praef; empty segments dropped); validation collatinus or whitaker (headword among the oracle's lemma keys) else quoted-form equality sharing the headword's first two letters when neither oracle analyses the surface; exactly one validated surface -> gold. Of 253107 Lewis & Short citations into works held here: located 161032, ambiguous 15059, not located 70169, locator not in our edition 6847. Match = the system's lemma equals the L&S headword after case, diacritic, u/v, i/j and homograph-digit normalisation; strict keeps u/v and i/j as printed. The token stream is the project's own (data/latin_corpus/tokens/); every system was run on it pre-tokenised, so there is no alignment step.

Honesty

Lewis & Short (1879) cites what its lexicographers found worth citing: this is the rare, dictionary-worthy stratum, not overall accuracy, and treebank test scores are not comparable with it. The Perseus L&S XML is incomplete and its CTS tags cover 74% of its citations. Only works with a Latin edition in canonical-latinLit are covered; L&S was written against older editions, so locators drift and the relocation rule (unit ±1) absorbs some of that. The validation oracles are themselves lexicon-driven analysers: a token neither analyser knows and that L&S does not quote is not a locus, which biases the set toward forms the lexica cover. No human reader has judged a sheet of these loci yet. Nothing here patches any system's output; every figure traces to a row in data/qc/lsgold/ls_gold_scored.csv.
