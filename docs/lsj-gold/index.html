How the loci were made

window = cited unit ±1 sibling; validation morpheus (headword in analyses, accent-blind) else quoted-form equality when Morpheus has no analysis; exactly one validated surface -> gold. Of 249090 LSJ citations into works held here: located 96462, ambiguous 12816, not located 113636 (mostly Morpheus coverage, being filled), locator not in our edition 26176. Match = the system's lemma equals the LSJ headword after accent/case normalisation; strict = exact; article-neutral maps the article's forms to ὁ before comparing.

Honesty

LSJ cites what a 1940 lexicographer found worth citing: this is the rare, dictionary-worthy stratum, not overall accuracy. The Perseus LSJ XML is incomplete. Only works held in First1K editions are covered. odyCy's lemmas are a frozen 2026-07 run; Dilemma is context-free on the surface; convention differences count against a system in the strict and blind columns and are partly undone in the article-neutral one. No human has validated the relocation yet; the blind salted sheet is in the repository.

Submit a system

Write <stem>.jsonl token caches for the covered editions with your lemmas ({i, surface, lemma} per token) and open a pull request adding them under submissions/<system>/; CI scores them with greek-lemma-audit lsjgold (pip install greek-lemma-audit) and the row is added at the next version.
