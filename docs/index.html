Galen Density Project — pages

Static pages built from the repository's outputs. Every number on them is traceable to a file in galen-density-map/; nothing here is a gloss or a translation.

  • LSJ-Gold leaderboard — lemmatizer accuracy on the dictionary-cited stratum of Ancient Greek (93,926 relocated loci over 54 authors, CC BY 4.0). JSON.
  • LS-Gold leaderboard — the Latin twin: lemmatizer accuracy on the words Lewis & Short cites (161,032 relocated loci over 33 authors, validated by Collatinus and Whitaker's Words, CC BY-SA 4.0). JSON.
  • Galen Term Explorer — any Galenic word: keyness, LSJ tier, Dilemma headword, punch-list label, contexts, Kühn loci.
  • Term Explorer for further authors — Diophantus, John Philoponus, Philodemus.
  • Galen First Drafts — machine first translations of the untranslated works, unverified (v0.1): Greek beside two model renderings, every technical term tied to its LSJ entry, three machine checks per unit, failures marked. Drafts for scholars to correct, not translations to quote.

Repository: github.com/Montblanctech/Galen. Audit kit: pip install greek-lemma-audit. Cite the concept DOI 10.5281/zenodo.21561962 (v3.0: 10.5281/zenodo.24046260).
