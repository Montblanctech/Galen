About the data

Built 2026-11-13 by galen-density-map/pipeline/firstdrafts/term_index.py from each work's term_table.csv; data: outputs/firstdrafts/_index/ (JSON and CSV). Lemma = LSJ entry where there is one (2,248 lemmas), else the Dilemma lemma. Only words the pipeline chose as target terms (rare or hard nouns and adjectives, at most eight per passage) are indexed, so a lemma's absence from a work means it was not a target there, not that Galen does not use it. The usual rendering of a lemma in a work is its commonest normalised rendering over A and B together.
