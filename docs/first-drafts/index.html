Galen First Drafts — machine first translations, unverified (v0.1)

Works of Galen that have no modern-language translation (census: phase1/README_translation_status.md), rendered twice by two language-model families with the same neutral prompt, aligned to the Greek, every technical term tied to its LSJ entry, three machine checks per unit, failures marked and kept. These are drafts for scholars to correct, not translations to quote. Spec: firstdrafts_v0_spec.md.

  • Adversus Lycum (Against Lycus), Kühn XVIIIA 196-245: 50 units, 7452 Greek words, 2 units failing two or more checks.
