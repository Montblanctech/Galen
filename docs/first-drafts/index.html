Galen First Drafts — machine first translations, unverified (v0.1)

Author of the drafts series: William Pepperman (Galen Density Project). Each work carries its own citation line and version.

Works of Galen with no English translation, most of them with no translation in any modern language (status and sources per work: phase1/README_translation_status.md), rendered twice by two language-model families with the same neutral prompt, aligned to the Greek, every technical term tied to its LSJ entry, three machine checks per unit, failures marked and kept. These are drafts for scholars to correct, not translations to quote. Spec: firstdrafts_v0_spec.md (cycle 1), firstdrafts_v02_spec.md (cycles 2 and 3).
