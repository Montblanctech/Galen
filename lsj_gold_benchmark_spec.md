# LSJ-Gold — a standing benchmark for Ancient Greek lemmatizers on the dictionary-cited stratum (spec 2026-11-06; **v0 built the same night**: 6,116 loci; odyCy 69.7 vs Dilemma 92.1; Hippocrates 61.3 / 93.4 — see `galen-density-map/data/qc/lsjgold/README.md`)

**Why.** Will, 2026-11-06: make the work something further researchers must use and cite. People cite what they have to run. Today the project is the only source of a number every lemmatizer paper will need: accuracy on the vocabulary a dictionary found worth citing. On Galen (1,850 LSJ loci, Kühn-relocated) odyCy scores 61.5%, Stanza 59.7/59.7, Dilemma 95.2%. That stratum is where the three neural systems agree with each other and are all wrong a third of the time. A benchmark that any new system is scored on, with a published table, becomes the citation nobody can skip.

**Feasibility (checked today against the 27 Perseus LSJ XML parts).** 419,808 LSJ citations carry a CTS URN (`n="urn:cts:greekLit:tlg0086.tlg010..."`): 873 authors, 1,822 works. 168,996 of them cite authors whose text is in this project's First1K reference corpus; 23 of the 50 largest authors have ≥ 200 citations each (Aristotle 21,322; Hippocrates 9,607; Septuagint 6,879; Theophrastus 6,095; Philo 4,860; Sextus 1,776; Apollonius Dyscolus 1,742; Iamblichus 1,275; Proclus 1,255 …). Galen has only 858 CTS-tagged citations (the Kühn map gave us 1,850 by a different route); Dioscorides none (cited by Wellmann numbering, untagged). Plato (25,856) and Homer (39,368) are Perseus, not First1K, and would need Perseus text.

**Design.**
1. **Relocation** = the M3 method, generalised: for each citation (headword, CTS URN with passage), find the cited headword's surface in the cited passage of the First1K edition (surface-unique rule: every occurrence of the matched surface in that passage must carry one system lemma, else `ambiguous`, counted); the gold lemma is LSJ's headword (Beta Code → Unicode, accent-blind key available). Expected yield from Galen's run: ~70% of citations relocate.
2. **Strata**: by author (≥ 200 relocated loci to report an author row), by LSJ sense count (thin / rich), by POS. Report Wilson 95% everywhere.
3. **Scorer** = `greek-lemma-audit` M3 plugin made author-general (`--m3-gold` any file in the gold schema), plus a `benchmark` command that takes any system's token JSONL for the covered works and returns the table. Systems in the first table: odyCy 0.7.0, Stanza perseus/proiel, Dilemma, Stoicheia (as the Galen run finishes), GreTa marked unavailable with reason.
4. **Convention layer** reported beside strict: article map (done), -ῶς adverbs under adjective (Dilemma vs LSJ), comparatives (βελτίων/ἀγαθός), Attic/Ionic spelling variants where LSJ heads one (τέτταρες/τέσσαρες). Each rule is a documented table, never applied silently.
5. **Release** = dataset (CSV + schema + provenance per locus) on Zenodo with a concept DOI and on Hugging Face; results table in the repo README; `CITATION.cff`; a JOSS paper for the kit (software) and a short data paper for the gold. Versioned: adding an author or a system is a new release, old numbers never change.
6. **Honesty**: LSJ cites what interested a lexicographer in 1940, not a random sample; the benchmark measures the rare, dictionary-worthy stratum and says so in its name; Perseus LSJ is incomplete; a convention-mapped score is a different number from a strict one and both are printed.

**What Will clicks** (none is a build): PyPI release of `greek-lemma-audit`; Zenodo/HF dataset uploads under his account; JOSS submission; the GitHub release. Everything else is the build session's.

**Effort.** Relocation generaliser + benchmark command: 2–3 days. First table over the 23 covered authors: one overnight run. Dataset packaging and the two papers' drafts: 2 days. Target: v3.1 "LSJ-Gold 0.1" within two weeks of v3.0.
